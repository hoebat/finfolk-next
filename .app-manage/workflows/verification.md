# verification

Run the configured checks for changed layers and repository-required acceptance commands. Use code.test facts with unique fact IDs for Clojure/DSL tests. Inspect actual assertion values, test counts and generated parity. Skipped, blocked, zero-test and stale evidence are not proof of completion. A successful build does not establish database or model behavior. Capture run IDs and remaining gaps using scripts/agent/report. Do not claim unimplemented adapters are verified. Deployment, publication and destructive data changes are separate explicit workflows.
